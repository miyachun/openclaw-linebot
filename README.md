啟動 Gateway    
在 PowerShell 執行：  
& "$env:APPDATA\npm\openclaw.ps1" gateway run  

另一視窗  
powershell  
& "$env:APPDATA\npm\openclaw.ps1" gateway status  

cmd:  
node "%APPDATA%\npm\node_modules\openclaw\openclaw.mjs" agent --agent main --message "你好，請用繁體中文簡短回覆"
